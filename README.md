# macci — downloads & updates

**[⬇︎ Download the latest macci for macOS](https://github.com/Kedarcv/Macci-Public/releases/latest)** (Apple Silicon + Intel, notarized).

Requires macOS 14.2 or later. After the first launch, macci keeps itself
up to date automatically via [Sparkle](https://sparkle-project.org) — this
repo hosts the [`appcast.xml`](appcast.xml) feed and the release DMGs.

The app's source is private; this repo is distribution only.
